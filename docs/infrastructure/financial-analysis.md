## 1. 総括

学校法人コンピュータ総合学園の2025年度決算は、**総資産423.2億円**、**純資産401.7億円**、**現金預金127.2億円**、借入金ゼロ。流動比率813%、負債比率5.35%で、資産・資金の蓄積（ストック）は引き続き極めて厚い。

一方、収益力（フロー）は縮小が続いている。

- **基本金組入前当年度収支差額は6.3億円**（前年度15.8億円、△60.2%）。事業活動収支差額比率は39.8%から**17.4%**に低下
- このうち4.35億円は特別支出「過年度修正額」（予算0.73億円）による一時的要因。これを除いた場合の基本金組入前当年度収支差額は10.6億円
- 構造的な変化は**教育活動収支差額の4年連続減少**（12.2億円 → 12.0億円 → 10.2億円 → 6.9億円 → **4.9億円**）。学生生徒等納付金は22.6億円で2022年度ピーク比△18.8%
- 経常収支差額9.2億円のうち**46.6%（4.3億円）は受取利息・配当金**であり、教育活動単体の黒字幅は運用収益とほぼ同水準まで縮小
- 翌年度分の学費である前受金収入は13.1億円（前年度比△9.3%、2021年度比△33.5%）、神戸電子専門学校の在学生は1,723名（2026年5月1日現在、前年比△1.8%、充足率87.5%）。減少幅は指標により異なるが、2026年度の納付金もさらに減少する見込み
- 施設関係支出6,014万円・設備関係支出1,328万円は、いずれも5年間で最小

財務的に投資余力が不足しているわけではないが、経営側にとっては収入減少局面での支出判断となる。

|------|--------:|--------:|--------:|--------:|--------:|
| 経常収支差額比率 | 42.1% | 40.2% | 37.0% | 31.6% | **27.5%** |
| 教育活動収支差額比率 | 36.9% | 34.5% | 30.4% | 22.6% | **16.8%** |

- **教育活動収支差額比率**: 教育活動収支差額 / 教育活動収入。納付金減少と管理経費・教育研究経費の増加が直接反映
- **経常収支差額に占める受取利息・配当金**: 経常黒字のうち運用収益が占める割合。教育活動の黒字縮小に伴い、運用収益への依存度が上昇

## 7. 財務上の特徴と強み

### 7-1. 極めて厚い資産・資金の蓄積
- **無借金経営**: 借入金残高ゼロ。利息支出もゼロ
- **潤沢な手元資金**: 現金預金 **127.2億円** + 有価証券 **134.0億円** = **約261.2億円**。このほか特定資産（積立金）55.0億円
- **低い負債比率**: 総負債21.5億円に対し純資産401.7億円（負債比率5.35%）。負債の増加は役員退職給与引当金・賞与引当金の新設によるもの

### 7-2. 安定した資産運用収入
- 受取利息・配当金は2021年度以降4年連続で増加し **年間4.3億円**（期末有価証券134.0億円に対し約3.2%）
- 資産売却差額（有価証券の売却益）は年間2.6億円

### 7-3. 黒字の継続
- 5年間すべてで基本金組入前当年度収支差額が黒字（6.3〜16.6億円）
- 翌年度繰越収支差額は2021年度末 **206.2億円** → 2025年度末 **249.0億円** に増加

### 7-4. 外部監査
- 監事監査に加え、会計監査人（清稜監査法人）による計算関係書類・財産目録の監査を受け、いずれも適正意見（§9）

## 8. 財務上の課題・リスク

### 8-1. 学生納付金と在学生数の減少
- 学生生徒等納付金は2022年度ピーク27.8億円から2025年度22.6億円へ **△18.8%**。3年連続の減少
- 先行指標の前受金収入は2021年度19.7億円から2025年度13.1億円へ **△33.5%**（前年度比△9.3%）。2026年度の納付金はさらに減少する見込み
- 神戸電子専門学校の在学生は1,889名（2024年）→ 1,755名（2025年）→ 1,723名（2026年）。収容定員1,970名に対する充足率は87.5%。2026年の在学生の減少幅（△1.8%）は前受金の減少幅（△9.3%）より小さく、前受金の減少には在学生数以外の要因（学科構成・修業年限・学費減免等）も含まれうる
- 日本人入学者の減少を留学生の増加で補う構造であり、留学生比率は約22%に達する

### 8-2. 教育活動の収益力低下
- 教育活動収支差額は4年連続で減少し4.9億円（教育活動収支差額比率16.8%）
- 収入が減る一方で、教育研究経費（+11.5%）・管理経費（+4.1%）は増加。人件費は△2.7%だが、人件費比率は33.10%に上昇
- 管理経費比率22.10%は5年間で最高

### 8-3. 運用収益への依存
- 有価証券134.0億円は総資産の31.7%
- 経常収支差額の46.6%を受取利息・配当金が占め、運用環境の変化が経常収支に直結する構造

### 8-4. 一時的要因による収支差額の変動
- 2025年度の基本金組入前当年度収支差額の大幅減少（△9.5億円）は、過年度修正額4.35億円、資産売却差額の減少（△2.4億円）、教育活動収支差額の減少（△2.0億円）、資産処分差額の増加（+1.1億円）による
- 過年度修正額は予算0.73億円に対し決算4.35億円で、内訳は公開資料に記載がない

### 8-5. 設備投資の縮小
- 施設関係支出6,014万円 + 設備関係支出1,328万円 = **7,342万円**で5年間の最小（2024年度は3億9,983万円）
- 設備関係支出は予算2,291万円自体が小さく、執行率も58%にとどまる
- 2025年度の施設整備は空調・給水・外壁で、ネットワーク設備への投資は事業報告書・自己点検評価報告書のいずれにも記載がない
- 注: 単価の小さい機器は設備関係支出ではなく教育研究経費・管理経費として処理される場合があるため、設備関係支出だけではIT関連支出の総額は測れない。教育研究経費支出は前年度比+5,667万円（+13.8%）だが、内訳は公開されていない

## 10. eduroamインフラ投資への示唆

| 項目 | 参考値（2025年度） |
|------|--------|
| 法人の現金預金残高 | 127.2億円 |
| 法人の経常収支差額 | 9.2億円 |
| 法人の教育活動収支差額 | 4.9億円 |
| 法人の年間施設関係支出 | 6,014万円 |
| 法人の年間設備関係支出 | 1,328万円（予算2,291万円） |
| 法人の年間教育研究経費支出 | 4億6,598万円 |

- **資金面の障壁はない**: 現金預金127.2億円・無借金であり、RADIUSサーバ・AP更新等の数百万〜数千万円規模の投資は資金残高の1%に満たない
- **ただし経営判断のハードルは上がっている**: 教育活動の黒字は4年連続で縮小し、2026年度も納付金の減少が見込まれる。提案は「余剰資金の活用」ではなく、**募集力・教育品質への投資**として費用対効果を示す必要がある
- **設備予算に対しては無視できない規模**: AP 30台のイニシャル費用は約85万〜780万円（`docs/ap/vendor-survey.md`）で、12棟への展開やスイッチ刷新を含めると増える。法人全体の年間設備関係予算2,291万円に対して大きな割合を占める可能性があるため、通常枠ではなく個別の予算措置として起案するのが確実。なお単価の小さいAPは経費処理される場合があり、どの予算区分に計上されるかは法人の会計処理基準による
- **訴求ポイント**:
  - 在学生の減少と留学生比率の上昇（約22%） — eduroamの国際相互利用は留学生にとって到着直後から使える接続手段であり、募集・受入れ環境の差別化要因になる
  - 第三者評価の受審（令和8年4月1日から5年以内） — 自己点検評価報告書は施設・設備の点検・更新計画を評価基準に含む
  - 神戸情報大学院大学の5か年事業計画（2021〜2025年度）が2025年度で終了 — 次期計画にeduroam・ネットワーク基盤整備を位置付ける機会
- KIC側は既にArubaの統合AP環境を整備済みであり、eduroam対応のSSID追加は追加コスト最小
- 財務的にはeduroam導入の意思決定は **経営判断・組織間調整の問題** であり、資金制約の問題ではない。ただし収入減少局面にあるため、投資対効果の説明がより重視される
